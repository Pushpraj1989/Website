# Real Estate Quality Gates
Audit desktop/tablet/mobile and Arabic/English. Verify WCAG 2.2 AA essentials: keyboard navigation, focus, semantic structure, contrast, alternative text, reduced motion, form errors and screen-reader usability. Check Core Web Vitals with realistic mobile throttling; target LCP <=2.5s, INP <=200ms and CLS <=0.1 at the 75th percentile. Check video fallback, posters, lazy loading, responsive sources, caching and non-blocking scripts. Validate that imagery accurately depicts the project, investment figures are approved, availability is current and claims are sourced. Verify lead form spam prevention, data minimization, explicit consent where required, safe file uploads and secure API keys. Test motion for jank, readability, excessive flashes, vertigo and RTL direction. Output PASS/FAIL, severity, evidence, remediation and retest results. Block release on critical issues.
