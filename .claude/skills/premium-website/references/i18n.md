# Arabic (and other second languages)

Every Gulf client gets an Arabic version. The kit builds it from the same data, so the two
languages never drift apart: same pages, same file names, same cart.

## Steps
1. `python3 tools/i18n.py extract <slug> --chunks 14000`
   - writes `data/i18n/<slug>.strings.json` (every visible string in `data/<slug>.json`)
   - and `data/i18n/work/<slug>.<n>.json` pieces for translators (several agents in parallel;
     give each its own scratch folder so helper scripts do not overwrite each other).
2. Translate each piece into `data/i18n/work/<slug>.<n>.ar.json` (`{"English": "Arabic"}`), following
   `data/i18n/GUIDE.md`: MSA for facts, medical and product text; light Omani dialect (الحين، حياك،
   عشان) only in headlines, buttons and nudges for retail and food brands; brand names, codes,
   degrees, numbers, emails, phones and URLs unchanged; HTML tags kept.
3. `python3 tools/i18n.py merge <slug>` then `python3 tools/i18n.py missing <slug>` (must be 0).
4. Check every chunk: same keys, same HTML tags, numbers kept or written as words. Strip
   invisible bidi marks. Fix names a translator guessed (place names transliterate, never translate).
5. Pick Arabic faces that match the English type: `brand.ar_display` / `brand.ar_body`
   (Cairo for heavy condensed sans, Amiri for editorial serif, El Messiri for elegant display,
   Noto Kufi Arabic as the default; body IBM Plex Sans Arabic). Only weights the font has are requested.
6. Build. Look at `sites/<slug>/ar/` on desktop and phone, then
   `python3 tools/qa.py <slug>/ar`.

## How it works
- `build/i18n.py` translates a copy of the raw data, keeping English titles as `_en_<key>`, so
  file names, cart SKUs and `@cat:` links are the same in both languages.
- Kit interface text (buttons, labels, script messages) comes from `build/i18n/ar.json`:
  `exact` strings, `patterns` for strings with numbers ("All 35 specialities"), `inline` for
  prices ("OMR 24.000" -> "24.000 ر.ع."). Scripts read the same dictionary through `window.T1L`.
- `shared/css/rtl.css`: Arabic type (no tracking, capitals or italics; taller lines; bolder
  display), mirrored arrows, side-placed pieces. Flex and grid flip by themselves.
- Animations never split Arabic into letters (letters join); sideways offsets mirror (`RTL` in fx.js).
- Image credits stay in English (licence attribution), marked left to right.

## Look for
- English left on the page: scan text nodes without Arabic letters (single lowercase labels and
  units like "kcal" or "400 g" belong in the dictionary).
- Copy colliding with a product or dish placed on one side (converge `--cx`, custom modules).
- Latin titles ending in punctuation show the full stop on the left in RTL: acceptable, or translate.
