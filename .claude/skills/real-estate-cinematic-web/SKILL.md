# Cinematic Real Estate Website
## Discovery
Determine target buyers, developer relationships, property availability, legal claims, lead routing, languages, CMS, project assets, brand kit, performance budget and launch requirements. Record assumptions explicitly.
## UX
Create information architecture for Home, Properties, Project Detail, Investment in Oman, Services, About, Insights and Contact. Separate verified facts from promotional copy. Design buyer and investor paths, inquiry CTA, WhatsApp, scheduled consultations, location context, filters, floor plans and project galleries. Use native Arabic copy review and true RTL layouts.
## Visual system
Use midnight navy #081522, champagne gold #C8A66B, warm ivory #F5F1E8, slate #667786. Elegant editorial headings and highly legible body typography. Avoid excessive glassmorphism, decorative noise, stock skyline imagery and nonfunctional animation. Establish typography, grids, spacing, cards, imagery treatment, states and design tokens.
## Motion
Storyboards for Tower Genesis hero, image mask reveals, floor selector, facade light sweep, spatial parallax, day-night transitions, project card depth, scroll pinned investment narrative, interactive map, smooth page transition. Respect prefers-reduced-motion and keyboard access. Use GSAP for scroll timeline, R3F for true 3D only where assets justify it, and optimized videos for cinematic media.
## Engineering
Recommend Next.js, TypeScript, Tailwind, accessible component primitives, GSAP, optional R3F, a structured CMS, localized routing, schema.org RealEstateAgent/Residence as appropriate, responsive images and lazy loading. No autoplay audio. Honor privacy, consent and Oman applicable marketing/legal review.
## Deliverables
Competitive moodboard, page-level wireframes, responsive visual prototype, motion storyboard, architecture, component inventory, CMS model, phased implementation plan and measurable acceptance criteria. Do not code the full website before design approval.
