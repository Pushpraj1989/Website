# Release quality report

Mark each item PASS, FAIL or N/A, with evidence (frame numbers, file names, timestamps).
Any FAIL on a critical item blocks release.

## Critical
- [ ] Project identity confirmed in writing (name, developer, location). Critical.
- [ ] Permission to reuse every source recorded in the manifest. Critical.
- [ ] Building silhouette, floor count and roof match the approved reference in every shot. Critical.
- [ ] Every synthetic or stylised shot carries the "Visualisation" label. Critical.
- [ ] No progress or completion claim the sources do not support. Critical.
- [ ] Logo is the original file at its original proportions. Critical.

## Visual
- [ ] No melting, warping or flickering in the building across scene boundaries.
- [ ] Camera motion is believable (no impossible turns, no jitter above 1 px per frame).
- [ ] Gold light stays within 35% intensity and does not clip highlights.
- [ ] Colour grade is consistent across shots.

## Website and performance
- [ ] Homepage hero loads its poster first; video starts after first paint.
- [ ] Mobile WebM under 2 MB; desktop WebM under 6 MB for the hero.
- [ ] Reduced-motion users get the poster frame, no autoplay.
- [ ] Captions or on-screen text are readable at 390 px width.

## Export
- [ ] 1920x1080 master, 1080x1920 social, 1280x720 hero, poster frame, WebM and MP4.
- [ ] Asset manifest complete: source, rights, prompt, model, date, label, approver.
