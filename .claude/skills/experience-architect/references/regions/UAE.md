# UAE UX Profile

Status checked: 2026-08-28.

## Official references
- UAE Design System 3.0: https://designsystem.gov.ae/
- Front-end accessibility/internationalisation: https://designsystem.gov.ae/guidelines/frontend-development

## Product rules
- For UAE Federal Government digital experiences, inspect current UAE Design System requirements/components before inventing alternatives.
- UAE Design System 3.0 uses WCAG 2.2 AA guidance and explicitly expects Arabic + English and testing with assistive technologies.
- Support Arabic RTL and English LTR as complete experiences, not translated overlays.
- Use logical CSS properties and test mixed-direction strings.
- Treat performance requirements from the applicable UAE assessment criteria as product requirements when in scope.

## Audit checklist
Arabic/English parity; RTL/LTR navigation; bilingual content expansion; forms; IDs/numbers/phone/account strings; focus/keyboard; screen reader; government identity/trust patterns; current component conformance.
