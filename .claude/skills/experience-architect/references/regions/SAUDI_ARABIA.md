# Saudi Arabia UX Profile

Status checked: 2026-08-28.

## Official references
- DGA National Design System / Platforms Code
- DGA Guideline for Web Accessibility of Digital Channels Content to Serve People with Disabilities and the Elderly, covering WCAG 2.2

## Product rules
- For Saudi government-related digital work, inspect current DGA/National Design System guidance and reusable components.
- Apply WCAG 2.2 as the accessibility reference where current DGA guidance applies.
- Include Arabic RTL + English/localized needs according to product scope; do not infer design preference from nationality.
- Consider elderly users and people with disabilities explicitly in target-user/audit coverage.

## Audit checklist
National-design-system fit; WCAG 2.2; Arabic/bidi; terminology; keyboard/screen reader; elderly/cognitive/motor barriers; identity/service-channel patterns; component consistency.
