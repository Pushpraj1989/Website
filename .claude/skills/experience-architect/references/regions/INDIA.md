# India UX Profile

Status checked: 2026-08-28.

## Official reference
- GIGW 3.0: https://guidelines.india.gov.in/gigw3/

## Product rules
- For Indian Government websites/apps, layer current GIGW requirements on top of the Experience Architect global baseline.
- GIGW 3.0 currently references WCAG 2.1 AA; this does **not** downgrade the skill's default WCAG 2.2 AA baseline. Meet both the current GIGW requirements and the stricter applicable product baseline.
- Inspect current GIGW evaluator/developer actions, accessibility, mobile friendliness, Unicode/regional-language behavior, cybersecurity, lifecycle, and information architecture requirements.

## Audit checklist
semantic structure; assistive technology; orientation; reflow; text spacing; forms/errors; language tagging; Unicode; regional-language content; mobile; government content/ownership/disclosure requirements where applicable.
