# Behavioral Psychology and Cognitive UX

## Core principle

Apply psychology to reduce effort and improve comprehension, not to manipulate consent or exploit cognitive bias.

## Review dimensions

### Attention
- Make the primary task/action perceptually clear.
- Avoid competing banners, motion, badges, and decorative emphasis.
- Use interruption-sensitive patterns for professional workflows.

### Working memory
- Keep required comparison information visible.
- Preserve filters/context when users move between detail and list views.
- Prefer recognition over recall.
- Externalize complex choices using summaries, comparison tables, previews, and checklists.

### Choice complexity
- Group choices meaningfully.
- Prioritize common/important actions.
- Use progressive disclosure where it reduces complexity without hiding essential options.
- Do not create artificial scarcity or urgency.

### Motor effort
- Place frequent actions near their context.
- Ensure appropriately sized targets and spacing.
- Avoid precision-dependent gestures as the sole input method.

### Mental models
- Use vocabulary users already understand.
- Follow established platform/domain conventions.
- If a novel interaction is necessary, teach it in context and provide recovery.

### Feedback and control
- Communicate state changes promptly.
- Provide undo where feasible.
- Keep users oriented during long-running or multi-step processes.

### Interruption recovery
For workflows likely to be interrupted:
- autosave safe work
- show last completed step/state
- preserve context
- make resume action obvious

### Decision quality
For high-impact decisions:
- expose relevant evidence
- explain consequences
- separate facts from recommendations
- prevent accidental commitment
- provide review before irreversible execution

### Gestalt / visual grouping
Use proximity, similarity, common region, continuity, and figure-ground to express structure. Never let visual grouping contradict semantic grouping or reading order.

## Manipulation gate

Reject:
- hidden costs
- confirmshaming
- fake countdowns
- preselected consent where inappropriate
- visually de-emphasized refusal when consent must be freely chosen
- obstruction of cancellation/deletion
- misleading button hierarchy
- disguised advertising/actions
- forced continuity

## Diagnostic questions

- What must the user remember to succeed?
- What can the UI remember for them?
- What is competing for attention?
- What choices can be grouped or deferred?
- What is the cost of a mistake?
- Does the interface match the user's mental model?
- Can the user confidently reverse or recover?
